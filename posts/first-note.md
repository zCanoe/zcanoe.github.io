agent = LLM + Harness

AI的迅速发展不得不接触学习agent，20年gpt爆火把AI(人工智能)带入到了各行各业，随之Agent的出现让生产力得到了质的飞跃。

在当下对于AI大家都不陌生，但是对于AI背后的原理以及AI如何回答出的问题想必了解的少。了解这些就得从LLM开始说起，也就是大语言模型。LLM的本质是去生成一段文字信息，为了去预测每下一个词语是什么，最初是通过统计学的方法去进行计算的，其核心思想是一个句子出现的概率等于句子中词语的连乘： 
  

$$
P = P(w1)*P(w1|w2)* ........*P(w1|w2|w3|....|wn)
$$

但是这样不可靠，像P(w1|w2|w3|....|wn)的概率可能在训练语料中从未出现，且统计计算的太多，为了解决这一个问题从而引入了N-gram架构，句子中每个词语出现的概率只与前面N个词语的概率相关，N是可以调整的相当于滑动窗口。但是这样也有问题，太依赖训练语料中特定的词组了，且对于意思相同的词语无法进行推理，如 robot learn，agent learn 在训练语料中，但是无法推理出learn agent 因为leanr agent 在训练预料中从未出现，很难计算出相似性。为了解决这些问题，从而转换到了让LLM像人一样思考的模式，即神经网络，通过空间向量去计算两个词语之间的相似性以及推理并通过多层权重得到最后的结果。通过余弦相似度去计算两个词语之间的相似，如果乘为1在余弦值为1，则完全相关。如果为0则是垂直关系表示不相关，如果为-1 则是180度。完全表示负相关。

对于LLM还有一定的知识：过拟合、梯度下降、学习率、反向传播。
过拟合是指训练过程中出现的噪音，出现以偏概全的情况，如训练样本中百分之八十认为该情况是对的，那么可能会导致对该情况的判断全对，一般情况下需要关闭部分神经元进行训练判断从而降低概率从的出现
反向传播是指如果训练的结果不符合预期，需要倒推原因并去调整训练材料的权重，从而符合预期
学习率是指在训练过程中调整权重的大小
梯度下降是指在三维空间下的曲率调整学习率的方向并无限接近预期结果的过程

通过以上得知LLM相当于是通过一定的算法预测得知文字语言的生成，相当于人类的大脑。那么人干活是通过大脑学习思考去指挥身体行动从而产生了劳动，那么ai是如何提升的生产力呢，和人类差不多，我们已经有了LLM这个大脑，那么我们也需要去指挥身体行动，那么就构成了Agent，这不过这里的身体是Harness。
